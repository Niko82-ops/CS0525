# CS0525 – Cyber Security Labs

In this repository I collected the practical labs and projects developed during my Cyber Security & Ethical Hacking training.

During this journey I moved from understanding how systems work to actively exploiting and defending them.

All activities were performed in controlled lab environments.

---

## UNIT 1 – Foundations

Here I built the technical foundations of cybersecurity:

- Networking fundamentals
- Operating Systems basics
- C and Python programming
- Introduction to Penetration Testing
- Firewalls and Cryptography

This phase helped me understand how systems and networks really work before attempting exploitation.

---

## UNIT 2 – Offensive Security

In this unit I focused on the attacker mindset:

- Information Gathering & Scanning
- Web and Network Attacks
- Metasploit usage
- Post-exploitation techniques
- Data Leak analysis

Here I started thinking like an attacker and understanding the full attack lifecycle.

---

## UNIT 3 – Defensive Security

This phase shifted my focus to defense:

- Malware Analysis
- Cyber Threat Intelligence
- Incident Response basics
- Splunk introduction
- Active Directory & Windows Server 2022
- IAM and Backup strategies

The Buffer Overflow project was one of the most challenging and rewarding parts of this path, allowing me to deeply understand memory management and exploitation techniques.

Here I understood how detection, analysis and response really work in real-world scenarios.

---

## Goal

The goal of this repository is to document my technical growth across both offensive and defensive cybersecurity domains.
